# 🛠️ DigiTools - Digital Marketplace

**DigiTools** is a simple, premium, and modern web application where users can seamlessly browse, discover, and purchase premium digital tools. Designed with a mobile-first approach, it focuses on delivering an ultra-smooth shopping experience through a clean, clutter-free user interface.

## 📝 Project Overview
ডিজিটালツール কেনাকাটার জার্নিকে সহজ করতে এই প্রজেক্টটি তৈরি করা হয়েছে। এটি একটি ইন্টারেক্টিভ কমার্স হাব হিসেবে কাজ করে, যেখানে রি-রেন্ডার বা পেজ রিলোড ছাড়াই ইউজাররা রিয়েল-টাইমে কার্ট ক্যালকুলেশন, আইটেম ম্যানেজমেন্ট এবং কন্ডিশনাল চেকাউট ইন্টারফেস এক্সপ্লোর করতে পারেন।

---

## ✨ Key Features
- **🛒 Interactive Cart System:** সহজে যেকোনো ডিজিটাল টুল কার্টে যুক্ত করার সুবিধা। এটি অটোমেটিক টোটাল প্রাইস ক্যালকুলেট করে এবং রিয়েল-টাইমে আইটেম রিমুভ করার সুবিধা দেয়।
- **📱 Mobile-First Responsive Layout:** Tailwind CSS এবং DaisyUI ব্যবহার করে তৈরি, যা মোবাইল, ট্যাবলেট এবং ডেস্কটপ—সব ডিভাইসে পারফেক্টলি রেসপন্সিভ।
- **⚡ Smart Conditional UI:** কার্ট খালি থাকলে চেকাউট বাটন বা এক্সট্রা স্টেপগুলো হাইড হয়ে থাকে। পেজ রিলোড ছাড়াই কার্টের স্টেট অনুযায়ী ইন্টারফেস ডাইনামিকালি চেঞ্জ হয়।
- **🔔 Live Alerts:** প্রতিটা অ্যাকশনের (Add to cart, Remove) জন্য React-Toastify এর মাধ্যমে চমৎকার নোটিফিকেশন অ্যালার্ট।

## 🚀 Technologies Used
- **Core Library:** React.js (Vite)
- **Styling:** Tailwind CSS
- **UI Component Library:** DaisyUI
- **Icons:** React Icons
- **Notifications:** React-Toastify
